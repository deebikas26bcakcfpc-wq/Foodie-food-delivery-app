📌 Project Overview

Foodie is a simple and user-friendly food delivery app UI designed in Figma.
The app allows users to browse restaurants, select food items, add them to the cart, checkout, and confirm their order.

🎯 Objective
To design a simple food delivery mobile application.
To create an easy and user-friendly interface.
To provide a smooth food ordering experience.
To demonstrate UI/UX design and prototyping skills.

✨ Features
Welcome / Start Screen
Food Search
Food Categories
Popular Restaurants
Restaurant Details
Add Food to Cart
Cart Management
Checkout Screen
Payment Method Selection
Order Confirmation
Track Order option
